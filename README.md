# Shweta Sharma, Fullstack Dev

A Next.js App Router portfolio with a server-rendered homepage, filterable project gallery, three case study routes, résumé download, and direct email and LinkedIn links.

## Run locally

Use Node.js 22 or newer.

    npm ci
    npm run dev

Open the local address printed by Next.js. Run npm run build to produce a deployable static website in out/. Host the contents of out/ on any static web host that serves directory index files.

## Edit the portfolio

Professional profile, contact links, experience, skills, and project case studies live in content/profile.js. The homepage biography and introduction live in app/page.jsx. Replace the photos and résumé in public/ with files of the same name, or update the corresponding paths.

The résumé is the existing portfolio PDF. The fullstack role preference is draft copy. Confirm both before sending to employers.
